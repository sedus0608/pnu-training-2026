# 🎓 2026 부산대학교 교직원 직무연수 카탈로그 포털

> **Pusan National University HRD Portal 2026**  
> 부산대학교 교직원 및 실무자를 위한 2026학년도 전체 32개 직무연수 과정을 한눈에 탐색하고 세부 커리큘럼을 확인할 수 있는 반응형 웹사이트입니다.

---

## 🌟 주요 특징

1. **구글 스프레드시트 무가공 실시간 연동 (Live Sync)**:
   - 별도의 백엔드 데이터베이스 없이 Google Sheets GVIZ CSV API와 **PapaParse**를 통해 브라우저 로딩 시 실시간으로 최신 연수 정보를 불러옵니다.
   - 관리자가 구글 시트에서 내용을 수정하면 페이지 새로고침만으로 즉시 사이트에 반영됩니다.
2. **다차원 스마트 검색 & 필터링**:
   - **이수구분 탭 필터**: `전체`, `필수`, `권장`, `선택`
   - **세부 드롭다운**: 10개 직무분야, 3개 교육방식(온라인/집합/혼합), 교육대상별 필터링
   - **실시간 인메모리 검색**: 과정명, 부서명, 직무 키워드 즉시 검색
3. **상세 페이지 및 원클릭 수강신청**:
   - URL 파라미터(`?code=...`) 기반 단일 연수 상세 정보 매핑
   - 핵심 스펙(방식, 시간, 정원, 대상) 및 학습 목표, 상세 커리큘럼 제공
   - 부산대학교 HRD 수강신청 링크 원클릭 연결 및 담당부서 직통 전화 연결
4. **안전한 보안 구조 (Zero Secret Leak)**:
   - 비공개 API 키나 토큰을 코드에 포함하지 않으며, 공개된 읽기 전용 GVIZ 엔드포인트를 안전하게 활용합니다.

## 📁 디렉토리 구조

```
├── index.html              # 메인 페이지 (카탈로그 목록, 다중 필터, 검색)
├── detail.html             # 상세 페이지 (단일 연수 커리큘럼, 수강신청 안내)
├── style.css               # 부산대 시그니처 네이비 기반 반응형 디자인 시스템
├── app.js                  # 구글 시트 실시간 연동, PapaParse 파싱, 필터 엔진
├── data-fallback.json      # 네트워크 지연 대비 32개 과정 로컬 백업 데이터
└── PLAN.md                 # 프로젝트 상세 작업 기획서
```
